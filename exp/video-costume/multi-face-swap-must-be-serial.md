## 场景

三人同框搞笑图。先用即梦文生图出构图基准（脸不是本人），再用 `gptimg edit` 把三张
LOCKED 定妆照的脸换进去。图片场景，非视频帧。

## 结论

**一次 `gptimg edit` 只换一张脸。** 把构图图 + 一张定妆照作为输入，prompt 里点名改哪个
位置的人，并把另外两张脸写进"绝对不要动"清单。三张脸就跑三次，串行。

一次把三张定妆照一起喂进去（`-i 构图 -i 脸1 -i 脸2 -i 脸3`）虽然能跑通、也能过审，
但每张脸的保真度都被摊薄，和不给定妆照直接拿原始生活照换脸的结果差不多。
这与 video-editor 的 `face-fidelity-degrades-with-person-count` 是同一个现象，在静态图
换脸环节同样成立。

**单点修图必须附带保留清单。** 每次 `edit` 都是整图重绘，没在 prompt 里点名保留的细节会
被"顺手优化"掉。所以单点修的 prompt 固定两段结构：

```
这次只改一处：<要改的东西>

【绝对不要动的部分】<把另外两张脸、构图、姿势、服装、道具、背景、灯光、
以及这次容易被牵连的那个具体细节，逐条点名>
```

道具和液体这类"物理效果"最容易掉，要单独点名。

## 证据

- 一次换三张脸（`-i mall_v1 -i left -i mid -i right`，12310 tokens）：中间那张脸仍明显比
  定妆照瘦长，像度没有比直接拿原始手机照换脸更好
- 改成只修中间一张脸（`-i mall_FINAL -i mid_LOCKED`，8972 tokens）：中间脸圆润度和五官
  对上了，且左右两张脸确实没被改动 —— 说明"绝对不要动"清单是有效的
- 但同一次调用把"奶茶从杯口泼出浇在自己头上"的头发湿渍和液体流全弄丢了，
  因为 prompt 里只列了脸和构图，没点名这个道具效果
- 再补一次只加奶茶浇头（7359 tokens），把三张脸写进不要动清单，成功补回且脸没退化

## 反例

以为"输入图给得越多越准"，把构图图和三张定妆照一起喂进去一次搞定 —— 结果等于没给定妆照。
以及单点修图时只写"只改中间那个人的脸"就提交，没列保留清单，于是修好了脸、丢了笑点道具，
要多花一次调用补回来。
