## 场景

都市名利场短片《局》，原剧本镜2 是「沈黎指尖把一枚U盘弹到大理石桌面上，
滑到顾影手边停住」，配台词「我偷的，是你男人。」。写完 `script.json` 跑校验直接被拦。

## 结论

**动态道具传递（弹、抛、递、滑行）在 AI 生成里几乎必崩** —— 道具会在半空消失、
变形，或者滑行轨迹糊成一团。正确做法是**交接不拍，只拍结果**：

- 原镜：回眸 + 弹出U盘 + U盘滑行停住 + 台词（一镜四事，且含道具交接）
- 改后：镜2 只演「回眸说话 + 指尖刚从桌面收回」；镜3 独立成一个**无人脸的静物插入镜**
  「U盘已经静止在桌面上，金属接口反着冷光」

观众会自行补出"她刚把东西推过来"。附带好处：无人脸的静物插入镜是全片最稳、
最便宜的一镜，还能给台词留白、给节奏一个下沉点。

**静态持物不算交接**，可以留（本片留了遥控器、香槟杯、桌上的U盘静物），
但**液体物理（香槟溢出）仍是最高风险项**，要在风险清单里单列，
并预备退化方案：崩了就改成"杯子倾斜、手指发抖"，不拍液体。

## 证据

`video-exp validate script.json` 在 `has_combat_or_props: true` 上直接判不通过：

```
✗ has_combat_or_props 为 true —— 打斗/道具交接必崩，剧本阶段就要去掉
```

改成"只拍静止结果"后 flag 落回 false，校验通过。用 gpt-image-2 出的静物插入帧
`k3_usb` 一次通过、画面干净无文字，印证了无人脸静物镜是最稳的一档。

这条同时划出了 `shot-continuity-over-editing-tricks` 的边界：那条铁律要求
"关键动作转折必须让观众看见"，但**"关键转折"只指决定、折返、发现、认出这类
改变剧情走向的动作**，不包括手势级动作。判断方法是问一句：

> 省掉它之后，第一次看的人能否解释画面之间发生了什么？

「男主折返」省掉 → 观众会问"他怎么突然回来了" → 必须拍。
「弹U盘」省掉 → 观众自动理解"东西是她放的" → 可以省。两条经验不矛盾，
一条管剧情转折，一条管道具手势。

## 反例

❌ 一镜写成：回眸 + 弹出U盘 + U盘在桌面滑行停住 + 说台词
✅ 拆成：镜2「回眸说话、指尖刚离桌」→ 镜3「U盘静止在桌面的微距特写（无人脸）」

❌ 因为"道具是剧情核心"就保留交接动作，指望负面词挡住崩坏 —— 挡不住，动作幅度
会直接挤掉服装和长相描述。
✅ 道具在剧情里的作用由**台词 + 静物结果镜**承担，动态过程一律不拍。
